## Contribution overview
This project was created as a collaborative effort by the PAPAA team for the horror maze game **Stalled**.

Each member contributed to the game in different ways, including:
- game design and concept development
- level and maze planning
- visual and storytelling elements
- gameplay flow and overall polish
- project coordination and presentation

## Project overview
This project contains a simple multi-page website built with HTML, CSS, and JavaScript.

Pages included:
- `index.html` — home page and project overview
- `about.html` — team story and PAPAA reveal section
- `style.css` — all styling and animation
- `script.js` — interactive behavior and scroll-based reveal logic

## Local preview
To run the site locally:

```bash
cd portfolio
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
